쓸 자리는 “언제”다. 비가 온 시각과 분포는 잘 잡는다 — 군산의 새벽 집중호우 구간이 그래프에 그대로 보인다. “오늘 새벽에 비가 왔다 / 지금은 그쳤다 / 6시간째 안 온다” 같은 타이밍 판정에 쓰고, 양이 필요하면 지금처럼 ASOS(weather_daily)와 Open-Meteo 를 쓴다.

# 이 창구가 주는 변수는 넷뿐이다 — RR(강수) CA(운량) LST(지표온도) ASR(일사).
# 다른 이름을 주면 서버가 <Error> [정의되지 않은 옵션] varn= : RR, CA, LST, ASR 을 돌려준다.
SAT_VARS = ("RR", "CA", "LST", "ASR")


def fetch_point_series(api_key, lat, lon, varn, kst_day, interval=30):
    """
    # summary
    좌표 하나의 KST 하루치를 interval 분 간격으로 받는다. RR 이면 30분 강수(mm) 다.

    ⚠ 한 번에 24칸이 상한이다(LST_MAX_ITEMS). _utc_windows 가 그 규칙으로 끊어 준다.
    ⚠ 24시간을 한 창으로 달라면 **504** 가 온다. 3시간(7칸)씩 끊고 실패하면 한 번 더 친다 —
      2026-08-31 하루(48칸)를 이 방식으로 전부 받았다.
    ⚠ tm1/tm2 는 UTC 다. KST 를 넣으면 9시간 어긋난 하루를 받는다.
    ⚠ 창 경계가 양끝 포함이라 같은 시각이 두 번 온다. 시각을 키로 접어 49칸을 48칸으로 만든다.

    # params
    api_key: KMA_API_KEY<br>
    lat, lon: 밭 좌표<br>
    varn: SAT_VARS 중 하나<br>
    kst_day: 받을 날(KST)<br>
    interval: 분 간격. 30 이 기본<br>

    # returns
    {UTC 'yyyymmddHHMM': 값 or None}. 시각 오름차순으로 읽으면 시계열이다
    """
    if varn not in SAT_VARS:
        raise ValueError(f"varn 은 {SAT_VARS} 중 하나여야 한다: {varn}")

    start, end = _kst_day_utc_range(kst_day)
    out: dict[str, float | None] = {}
    # 3시간 = 7칸. 24칸 상한 안이고 504 가 안 나는 크기다(실측)
    for w_start, w_end in _utc_windows(start, end, interval, max_items=7):
        chunk = _sat_chunk(api_key, lat, lon, w_start, w_end, varn, interval)
        for i, key in enumerate(sorted(chunk, key=lambda k: int(k[6:]))):
            at = w_start + timedelta(minutes=interval * i)
            out[at.strftime("%Y%m%d%H%M")] = clean(chunk[key])
    return out


def _sat_chunk(api_key, lat, lon, w_start, w_end, varn, interval, tries=2):
    """단일 호출 + 재시도. 504 와 비JSON 응답을 같은 실패로 본다."""
    for _ in range(tries):
        resp = _get(
            f"{CGI_URL}/nph-arcltr_sat_txt",
            {
                "authKey": api_key,
                "tm1": w_start.strftime("%Y%m%d%H%M"),
                "tm2": w_end.strftime("%Y%m%d%H%M"),
                "int": interval,
                "lat": lat,
                "lon": lon,
                "varn": varn,
                "disp": 2,
            },
        )
        if resp:
            row = resp[0]
            return {k: v for k, v in row.items() if k.startswith("TM_INT")}
        time.sleep(1)
    # 한 창이 비어도 하루 전체를 버리지 않는다 — 그 시각만 결측으로 남는다
    return {}

"""30분 강수 시계열에서 '언제 왔나' 를 읽는다.

⚠ **양(量)으로 쓰지 않는다.** RR 은 ASOS 실측 대비 43~78% 로 일관되게 적게 나온다
  (2026-08-31 군산 120.6/154.0 · 대전 61.8/94.3 · 보령 52.9/122.0 실측).
  "필요 30mm 인데 20mm 왔다" 같은 판정에 쓰면 늘 물이 모자란 쪽으로 기운다.
  양이 필요하면 weather_daily(ASOS) 와 Open-Meteo 를 쓴다.
⚠ 이 모듈이 내는 것은 **시각**이다 — 마지막으로 비가 온 때, 지금 오고 있나, 몇 시간째 마른가.
"""

# 이보다 적으면 "안 온 것" 으로 본다. 레이더 추정의 바닥 잡음이 0.1~0.2mm 로 깔린다
TRACE_MM = 0.3
# 이 시간 이상 비가 없으면 "그쳤다" 로 본다. 소나기 사이 공백을 한 번의 비로 묶는 창
GAP_HOURS = 3


def last_rain_at(series):
    """
    # summary
    마지막으로 유의미한 비가 온 시각. 하루 종일 안 왔으면 None.

    # params
    series: fetch_point_series 결과 {UTC: mm}<br>

    # returns
    UTC 문자열 또는 None
    """
    wet = [t for t, v in series.items() if v is not None and v >= TRACE_MM]
    return max(wet) if wet else None


def raining_now(series, now_utc):
    """지금(가장 가까운 칸)에 비가 오고 있나. 결측이면 False 가 아니라 None 이다 —
    '안 온다' 와 '모른다' 를 섞으면 조언이 거짓말을 한다."""
    if not series:
        return None
    nearest = min(series, key=lambda t: abs(int(t) - int(now_utc)))
    v = series[nearest]
    return None if v is None else v >= TRACE_MM


def dry_hours(series, now_utc):
    """마지막 비로부터 몇 시간이 지났나. 자료 안에 비가 없으면 None(자료가 짧아서일 수 있다)."""
    last = last_rain_at(series)
    if last is None:
        return None
    return round((_to_dt(now_utc) - _to_dt(last)).total_seconds() / 3600, 1)


def rain_episodes(series):
    """비가 온 구간을 (시작, 끝, 합계mm) 로 묶는다. GAP_HOURS 이상 비면 다른 구간이다.

    화면의 '오늘 새벽 3시~6시에 22mm' 같은 문장이 여기서 나온다.
    """
    episodes, cur = [], None
    for t in sorted(series):
        v = series[t]
        wet = v is not None and v >= TRACE_MM
        if wet and cur is None:
            cur = {"from": t, "to": t, "mm": v}
        elif wet:
            cur["to"], cur["mm"] = t, cur["mm"] + v
        elif cur and _gap_hours(cur["to"], t) >= GAP_HOURS:
            episodes.append(cur); cur = None
    if cur:
        episodes.append(cur)
    return episodes

/**
 * ---------------------------------------------
 * [Feature]: 레이더 에코 오버레이 (카카오)
 *
 * [Description]
 * - 기상청이 주는 것은 **투명 배경 PNG 한 장**이다. 해안선도 격자도 없다 —
 *   우리 지도를 깔고 그 위에 얹으라는 뜻이라 GroundOverlay 가 맞다.
 * - ⚠ 위치 정합은 **우리가 요청에 넣은 bbox 로만** 맞출 수 있다. meta=1 을 줘도
 *   같은 PNG 가 오고 좌표 메타가 따로 오지 않는다(실측). 그래서 요청의
 *   stLon/stLat/edLon/edLat 을 그대로 LatLngBounds 로 재사용한다 — 한쪽만 바꾸면 어긋난다.
 * - ⚠ 이미지 URL 에 authKey 가 들어간다. **브라우저로 직접 부르지 않는다** —
 *   Next 라우트가 대신 받아 전달한다(ai-service 토큰과 같은 이유: 키가 새면 우리 쿼터가 샌다).
 *
 * [Usage]
 * ```tsx
 * useRadarOverlay(map, "202307071500", true);
 * ```
 * ---------------------------------------------
 */

// 요청 bbox 와 오버레이 bounds 는 **한 곳에서** 만든다. 두 군데에 적으면 반드시 어긋난다
export const RADAR_BBOX = {
  stLon: 48.19729473179383, stLat: 36.05394599513232,
  edLon: 162.3512886531648, edLat: 3.3720585707135684,
};

export function useRadarOverlay(
  map: kakao.maps.Map | null,
  analTimeUtc: string | null,
  show: boolean,
) {
  useEffect(() => {
    if (!map || !analTimeUtc || !show) return;
    const sdk = window.kakao;

    // 키는 서버에만 있다. 라우트가 기상청에서 받아 image/png 로 그대로 흘려준다
    const src = `/api/weather/radar?analTime=${analTimeUtc}`;

    const bounds = new sdk.maps.LatLngBounds(
      new sdk.maps.LatLng(RADAR_BBOX.edLat, RADAR_BBOX.stLon), // 남서
      new sdk.maps.LatLng(RADAR_BBOX.stLat, RADAR_BBOX.edLon), // 북동
    );
    const overlay = new sdk.maps.GroundOverlay(src, bounds, { opacity: 0.6 });
    overlay.setMap(map);

    // 시각을 바꾸면 이전 장을 반드시 걷는다 — 안 걷으면 10분치가 계속 쌓여
    // 화면이 점점 붉어진다(에코가 겹쳐 보인다)
    return () => overlay.setMap(null);
  }, [map, analTimeUtc, show]);
}

  const upstream = await fetch(radarUrl(analTime), { next: { revalidate: 300 } });
  // 자료가 없는 시각이면 기상청이 **200 에 HTML 안내 페이지**를 준다. 그걸 그대로
  // 흘리면 지도에 깨진 이미지가 뜬다 — content-type 을 보고 204 로 바꿔 화면이 조용히 넘어가게 한다
  const type = upstream.headers.get("content-type") ?? "";
  if (!type.startsWith("image/")) return new Response(null, { status: 204 });

  return new Response(upstream.body, {
    headers: { "content-type": type, "cache-control": "public, max-age=300" },
  });
}
