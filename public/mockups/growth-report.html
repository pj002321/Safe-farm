📋 요약

배추가 결구기에 들어섰습니다. 표준 결구 적기(15~16°C)보다 낮 기온이 아직 높아 속이 천천히 차는 중입니다.

같은 조건의 평년 배추밭과 비교하면 생육 자체는 순조롭지만, 최근 이레 동안 비가 0.1mm밖에 오지 않아 토양이 마른 상태입니다.

✅ 할 일

  • 오늘~내일 중 이동식 스프링클러나 물뿌리개로 물 주기
  • 짚 덮기(멀칭)로 토양 수분 증발 늦추기
  • 결구 진행 상태를 사흘 뒤 다시 확인하기

⚠️ 주의

내일 최저기온이 15.0°C로 결구 적기 하한에 가깝습니다. 이후 급격한 저온특보가 뜨면 알림으로 다시 안내합니다.

{
  "seed_date": "2026-07-09",
  "today": "2026-09-14",
  "crop": "배추",
  "stage": "결구기",
  "gdd_cum": 384,
  "gdd_target": 520,
  "deviation_from_normal_c": 1.2,
  "rain_7d_mm": 0.1,
  "tmin_tomorrow_c": 15.0
}

이 요약은 위 입력값만으로 생성됩니다. 병해충 진단은 하지 않으며, 관찰 포인트 안내까지만 제공합니다. 위성 데이터는 이 리포트에 직접 쓰이지 않고, 지역 단위 이상기후 조기경보에만 별도로 쓰입니다.
